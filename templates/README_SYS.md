# System Configuration Reference

This directory contains configuration files for the Arch Linux environment on this ThinkPad, generated by `backup-dotfiles.sh`.

> [!CAUTION]
> **MANUAL RESTORATION REQUIRED.** Do not use automated scripts to blindly overwrite system files. System-specific identifiers (e.g., UUIDs in `fstab` and in systemd-boot entries) must be verified against current hardware IDs to prevent boot failure. Misconfiguration of bootloaders or kernel parameters may render the system unbootable.

Compare every file with the live version before copying it:

```bash
diff -u /etc/thinkfan.conf thinkfan.conf
sudo cp thinkfan.conf /etc/thinkfan.conf
```

## Restore Order

1. **Pacman**: `pacman.conf` and `hooks/`, then `sudo pacman -Syu` (section 4).
2. **Packages**: official repositories, then AUR, then Flatpak (section 4).
3. **Configs**: `/etc` files from sections 1–3, after diffing each one.
4. **fstab**: merge options only, then verify (section 1).
5. **Initramfs**: `sudo mkinitcpio -P` (section 1).
6. **Bootloader**: loader entries and `bootctl` (section 6).
7. **Services**: throttled, thinkfan, optimus-manager, zram (sections 1–3).
8. **Reboot**, then restore runtime environments (section 5).

## 1. Boot & Hardware

* **fstab**: `/etc/fstab`. Contains partition mount points and options. Copy only relevant mount options (e.g., `x-systemd.automount`). **NEVER overwrite existing UUIDs** with old ones from this backup.
  * *Current IDs*: `lsblk -f`
  * *Verify before rebooting*: `sudo findmnt --verify && sudo mount -a`
* **mkinitcpio.conf**: `/etc/mkinitcpio.conf`. Check `HOOKS` and `MODULES` against the current setup (e.g., `udev` vs `systemd`, encryption hooks) before copying.
  * *Post-restore*: `sudo mkinitcpio -P`
* **grub (fallback)**: `/etc/default/grub`. Only relevant if GRUB is installed; systemd-boot is primary (section 6).
  * *Post-restore*: `sudo grub-mkconfig -o /boot/grub/grub.cfg`
* **throttled.conf**: `/etc/throttled.conf`. CPU/Undervolt parameters.
  * *Apply*: `sudo systemctl enable --now throttled`
* **thinkfan.conf**: `/etc/thinkfan.conf`. Thermal control configuration.
  * *Requires* fan control in the kernel module, otherwise the service fails:
    `echo "options thinkpad_acpi fan_control=1" | sudo tee /etc/modprobe.d/thinkpad_acpi.conf`, then reboot.
  * *Apply*: `sudo systemctl enable --now thinkfan`

## 2. Graphics

* **optimus-manager.conf**: `/etc/optimus-manager/optimus-manager.conf`. GPU management configuration. Ensure appropriate modes are set based on current driver state.
  * *Apply*: `sudo systemctl enable --now optimus-manager`
  * optimus-manager only manages X11 sessions; it has no effect in a Wayland session.

## 3. Zram Configuration

* **zram-generator.conf**: `/etc/systemd/zram-generator.conf`. Zram block device parameters.
* **99-vm-zram-parameters.conf**: `/etc/sysctl.d/99-vm-zram-parameters.conf`. Kernel `sysctl` memory parameters.
* **Activation**:

```bash
sudo systemctl daemon-reload
sudo systemctl restart systemd-zram-setup@zram0.service
sudo sysctl --system
```

* **Verify**: `zramctl` and `swapon --show`

## 4. Package Management

* **pacman.conf**: `/etc/pacman.conf`. Configuration for package operations. Restore before installing packages so enabled repositories (e.g., `[multilib]`) match.
  * *Post-restore*: `sudo pacman -Syu`
* **hooks/**: `/etc/pacman.d/hooks/`. Custom pacman hooks (e.g., `99-sync-kernel.hook`). Restore before reinstalling kernels so the hooks run.
  * *Restore*: `sudo mkdir -p /etc/pacman.d/hooks && sudo cp hooks/*.hook /etc/pacman.d/hooks/`
* **installed-packages.txt**: All explicitly installed packages (official and AUR combined). Reference only.
* **pkglist-official.txt**: Explicitly installed packages from official repositories.
  * *Restore*: `sudo pacman -S --needed - < pkglist-official.txt`
  * If pacman aborts because a package no longer exists, install only those still in the repositories:
    `sudo pacman -S --needed $(comm -12 <(pacman -Slq | sort) <(sort pkglist-official.txt))`
* **pkglist-aur.txt**: Explicitly installed AUR (foreign) packages.
  * *Bootstrap yay*:

```bash
sudo pacman -S --needed git base-devel
git clone https://aur.archlinux.org/yay-bin.git && cd yay-bin && makepkg -si
```

  * *Restore*: `yay -S --needed - < pkglist-aur.txt`
* **flatpak/**: Flatpak apps (`apps-system.txt`, `apps-user.txt`: app ID and remote), remotes (`remotes-*.txt`) and permission overrides.
  * *Add Flathub*: `flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo`
  * *Restore apps*:

```bash
while read -r app origin; do flatpak install -y --noninteractive "$origin" "$app"; done < flatpak/apps-system.txt
while read -r app origin; do flatpak install -y --noninteractive --user "$origin" "$app"; done < flatpak/apps-user.txt
```

  * *Restore overrides*: `mkdir -p ~/.local/share/flatpak && cp -r flatpak/user/overrides ~/.local/share/flatpak/` and `sudo cp -r flatpak/system/overrides /var/lib/flatpak/`
  * Remotes other than Flathub: re-add them with their `.flatpakrepo` file; the URL in `remotes-*.txt` does not include the signing key.

## 5. Runtime Environments

* **julia-global**: Contains `Project.toml` and `Manifest.toml` from the newest `~/.julia/environments/v1.x/`.
  * *Restore*: Place files in `~/.julia/environments/v1.x/` (matching the installed Julia version) and run `julia -e 'using Pkg; Pkg.instantiate()'`.
* **~/dotfiles/venvs/**: Specs for the envs managed by `upgrade-numerics.sh`. This is the preferred restore path for `~/venvs/*`. Each `<env>.lock/` holds `requirements.in`, the exact `requirements.txt`, optional `uv.env` (e.g., `UV_TORCH_BACKEND=cu126`) and `smoke.py`.
  * *Restore*:

```bash
mkdir -p ~/venvs
cp ~/dotfiles/venvs/upgrade-numerics.sh ~/venvs/
cp -r ~/dotfiles/venvs/*.lock ~/venvs/

uv venv ~/venvs/numerics --python /usr/bin/python
uv pip sync ~/venvs/numerics.lock/requirements.txt --python ~/venvs/numerics/bin/python

uv venv ~/venvs/pytorch_env --python /usr/bin/python
env UV_TORCH_BACKEND=cu126 uv pip sync ~/venvs/pytorch_env.lock/requirements.txt \
  --python ~/venvs/pytorch_env/bin/python
```

  * If a sync fails because the Python version changed, re-resolve from `requirements.in` instead: `~/venvs/upgrade-numerics.sh` and `~/venvs/upgrade-numerics.sh -e pytorch_env`.
* **python-envs**: Snapshots of every venv found under `~` (`<label>-version.txt`, `<label>-requirements.txt`), plus `global-pacman-python.txt`, `global-requirements.txt`, `pipx-apps.txt`, `conda-<env>.txt` and `<label>-julia_env/` where present.
  * *Restore a venv not covered by `~/dotfiles/venvs`*:

```bash
uv venv <path> --python /usr/bin/python
uv pip install -r <label>-requirements.txt --python <path>/bin/python
```

  * Lines such as `torch==...+cu126` need `env UV_TORCH_BACKEND=cu126` in front of `uv pip install`. The pins match the Python version in `<label>-version.txt`; on a newer Python some may need loosening.
  * *juliacall projects*: copy `<label>-julia_env/*.toml` into `<venv>/julia_env/`; juliacall installs the Julia packages when it is first imported.
  * *Global user packages*: `pip install --user` is blocked on Arch (PEP 668). Use the `python-*` packages from `global-pacman-python.txt` (already in `pkglist-official.txt`), or install command-line tools with `pipx` or `uv tool install`. `global-requirements.txt` is for reference.
  * *pipx apps*: `cut -d' ' -f1 pipx-apps.txt | xargs -n1 pipx install`
  * *Conda envs*: `conda create -n <env> --file conda-<env>.txt`

## 6. Systemd-Boot (Primary)

Configurations located in the EFI System Partition under `/loader/` (find the ESP with `sudo bootctl -p`). `random-seed` is excluded from the backup on purpose.

* **loader/loader.conf**: Default entry, timeout and editor settings.
* **loader/entries/\*.conf**: Kernel, initramfs and kernel parameters for each boot entry.
  * Entries reference the root partition (`root=UUID=...` or `root=PARTUUID=...`). Same rule as `fstab`: keep the current IDs from `lsblk -f` or `blkid`, and copy only the other options.
  * *Restore*: `ESP=$(sudo bootctl -p)`, then `sudo cp loader/loader.conf "$ESP/loader/"` and copy the edited entries into `"$ESP/loader/entries/"`.
* *Post-restore*: On a fresh install run `sudo bootctl install`; on an existing one run `sudo bootctl update` to ensure the bootloader is correctly synchronized.
* *Verify*: `sudo bootctl list` shows every entry with the kernel and initramfs paths it uses.
